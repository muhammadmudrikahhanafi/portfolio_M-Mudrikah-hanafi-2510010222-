PROYEK LANDING PAGE KATALOG UNIT USAHA HMP-TI ITS

Isi folder:
- index.html : struktur dan konten halaman website.
- style.css  : seluruh desain dan tata letak website.
- script.js  : fitur detail unit usaha (modal) dan menu navigasi mobile.

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder landing_page_hmp_ti di Visual Studio Code.
3. Buka file index.html.
4. Jalankan dengan browser (atau gunakan ekstensi Live Server jika tersedia).

Catatan:
- Konten empat unit usaha mengikuti deskripsi pada petunjuk tugas.
- Informasi harga, jam operasional, kontak, dan detail operasional tidak dicantumkan karena tidak tersedia di modul. Hubungi pengurus HMP-TI untuk data resmi.
- Website menggunakan HTML, CSS, dan JavaScript dasar tanpa framework.
- Google Fonts memerlukan koneksi internet; jika tidak tersedia, website tetap memakai font cadangan.

Sebelum pengumpulan:
- Buat repository GitHub dengan nama portfolio_nama_npm sesuai instruksi modul.
- Upload file proyek ke repository.
- Aktifkan GitHub Pages.
- Buat file TXT bernama NamaLengkap_NPM_SUB-DIVISI.txt, lalu isi link repository dan domain website.
